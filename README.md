# Life Fitness Pro — MD Service Demo

This is a **demo concept**, not an officially commissioned website.

## Files
- `index.html` — page structure/content
- `style.css` — responsive design and animations
- `script.js` — mobile menu, scroll reveal, progress bar
- `assets/` — reserved for future local assets

## GitHub Pages
Upload all files to a GitHub repository and enable GitHub Pages from:
Settings → Pages → Deploy from a branch → main → / (root)

## Important
- Public business information used in this demo came from the Google Maps information supplied for this project.
- No membership prices, client counts, awards, or other unverified claims were invented.
- The site uses external Google Fonts and Unsplash-hosted photos. For a final client website, replace them with approved/local assets if needed.
- The Google review excerpt is presented as an excerpt and should be replaced/verified before commercial publication.
