# Life Fitness Pro — MD Service Multi-Page Demo

A multi-page GitHub Pages compatible static website converted from the original one-page Life Fitness Pro demo while preserving its visual identity.

## Pages
- index.html — Home
- about.html — About
- programs.html — Programs / Services
- trainers.html — Trainers
- gallery.html — Gallery
- contact.html — Contact

## Structure
- css/style.css
- js/script.js
- images/ (reserved for approved local business assets)

## Deployment
Upload the project contents to the repository root and enable GitHub Pages from the main branch/root.

## Notes
- No backend, Node.js, React, Vite, npm or build system is required.
- All internal navigation uses relative paths.
- The supplied public business information is used as demo content.
- Trainer names/details are deliberately not fabricated; the trainer page uses clearly marked demo profiles until verified details are supplied.
- Gallery imagery is remote demo imagery and should be replaced with approved Life Fitness Pro photographs before commercial publication.
- The Google review excerpt/rating shown on the original demo should be verified before commercial publication.
